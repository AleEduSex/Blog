# Blog aleedusex.net Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Blog statico `/blog/` coerente con la landing, pubblicabile da Claude seguendo una procedura.

**Architecture:** Un file HTML per articolo generato a mano da `_modello.html`; stile condiviso in `blog/blog.css`; `robots.txt` + `sitemap.xml`; landing modificata solo con 3 link. La "suite di test" è `verifica.sh` nella radice.

**Tech Stack:** HTML5, CSS scritto a mano, Google Fonts (DM Serif Display, Source Serif 4), bash + git per le verifiche. Nessuna build, nessun npm, nessun JS nelle pagine del blog.

Spec: `docs/superpowers/specs/2026-09-21-blog-design.md` (fonte di verità per contenuti e layout).

- Colori: cream `#F0E7D5`, paper `#F8F1E0`, burgundy `#7A1E2B`, burgundy-deep `#5C1520`, ink `#1A1A1A`, line `rgba(122,30,43,0.30)`

- URL articoli: `/blog/<slug>.html`; canonical assoluti su `https://aleedusex.net`
- Favicon: solo `/favicon-192.png`

- Nessun file di lavoro dentro `site/`
